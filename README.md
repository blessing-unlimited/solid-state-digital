# SolidStateDigital
Solid State Digital Website

A modern, responsive landing page for Solid State Digital, a web solutions service focused on helping small and local businesses build, repair, and maintain their websites.

This project is a static website built using HTML and CSS, designed to showcase services, build credibility, and provide a clean user experience.

# Overview

Solid State Digital provides web services such as website development, maintenance, and optimization for small businesses. This website acts as the company’s digital presence and includes:

- A hero section introducing the business
- Services offered
- About section
- Testimonials section (with placeholder state for future client feedback)
- Modern UI design with subtle animations and gradients
- SEO and social sharing optimization

# Features
- Responsive Design – Works on desktop, tablet, and mobile screens
- Modern UI – Gradient backgrounds, glow effects, and animated elements
- SEO Optimization – Meta tags for search engines and social media previews
- Smooth Scrolling Navigation
- Service Cards Layout for presenting offerings clearly
- Testimonial Placeholder System for future client reviews
- Pure HTML + CSS – No frameworks required

# Technologies Used
- HTML5
- CSS3
- Google Fonts
- DM Sans
- DM Serif Display
- Caveat
